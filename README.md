# Fono Report

Sistema desktop desenvolvido em Java para auxiliar no registro de atendimentos fonoaudiológicos e na geração de relatórios.

## Objetivo

O projeto busca automatizar tarefas repetitivas relacionadas ao registro de atendimentos e elaboração de relatórios, facilitando a organização das informações e reduzindo o trabalho manual.

## Tecnologias

* Java
* Java Swing
* Git
* GitHub
